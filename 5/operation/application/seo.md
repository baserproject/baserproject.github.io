# SEO設定

コンテンツやブログ記事などに、ディスクリプションやOGP（Open Graph Protocol）などのSEO用のメタタグを設定する機能です。  
コアプラグイン BcSeo により提供されます。

## 利用の準備

BcSeo は初期状態ではインストールされていません。  
また、インストールしただけでは設定した内容はフロントページに出力されません。次の2つの手順が必要です。

### 1. プラグインをインストールする

管理画面の「設定」＞「プラグイン管理」より BcSeo（SEO設定） をインストールします。

### 2. テーマにメタタグを出力するコードを記載する

利用中のテーマのレイアウトファイル（`templates/layout/default.php` など）の `<head>` 内に、次のコードを記載します。

```php
<?php $this->BcBaser->seoMeta() ?>
```

## 設定できる項目

| 項目 | 出力されるタグ | 設定できないコンテンツ |
| --- | --- | --- |
| ディスクリプション | `<meta name="description">` | － |
| キーワード | `<meta name="keywords">` | － |
| カノニカル URL | `<link rel="canonical">` | サイト / ブログコンテンツ / ブログカテゴリ / カスタムコンテンツ |
| OG タイトル | `<meta property="og:title">` | サイト |
| OG ディスクリプション | `<meta property="og:description">` | － |
| OG タイプ | `<meta property="og:type">` | － |
| OG イメージ | `<meta property="og:image">` | － |
| OG URL | `<meta property="og:url">` | サイト / ブログコンテンツ / ブログカテゴリ / カスタムコンテンツ |

- 値が設定されていない項目は出力されません。
- カノニカル URL・OG URL は、相対パスで入力した場合、出力時に絶対URLへ変換されます。
- OG イメージは、そのページ自身に設定がない場合、そのコンテンツやブログ記事に登録されたアイキャッチ画像を参照します。アイキャッチ画像も無い場合は、「[設定値の表示優先度](#設定値の表示優先度)」に従って優先度の低い設定値を参照します。

## 設定できる場所

インストールすると、次の編集画面に「SEO設定」の入力欄が追加されます。

- サイト
- コンテンツフォルダ
- 固定ページ
- メールコンテンツ
- ブログコンテンツ
    - ブログカテゴリ
    - ブログ記事
- カスタムコンテンツ
    - カスタムエントリー

## 設定値の表示優先度

1つのページには、次の順序で設定値が引き継がれます。優先度の高い設定値が存在しない場合に、優先度の低い設定値が出力されます。

- ブログ記事・ブログカテゴリ ＞ そのブログコンテンツ ＞ サイト
- カスタムエントリー ＞ そのカスタムコンテンツ ＞ サイト
- それ以外：そのコンテンツ（固定ページ・コンテンツフォルダなど） ＞ サイト

引き継がれるのは、サイトと、表示中のページ自身が属するコンテンツの設定だけです。  
**コンテンツツリー上の親子関係は参照しません。** 例えばコンテンツフォルダに設定した値が、そのフォルダ配下の固定ページに引き継がれることはありません。フォルダの設定は、フォルダ自身のページにのみ適用されます。

また、次の項目はページごとに固有の値となるため、上記の引き継ぎを行いません。

- カノニカル URL
- OG タイトル
- OG URL

## 項目の追加・編集・削除

設定を変更することで、出力する項目を追加・編集・削除できます。  
標準の設定は `plugins/bc-seo/config/setting.php` に記載されています。

設定の変更後、プラグイン管理の BcSeo の管理アイコンよりDB更新画面（`/baser/admin/bc-seo/seo_configs/update_db`）を開き、実行するとデータベースが更新されます。
